# Candidate-page evidence

Use this reference only after SERP collection has produced candidate URLs.

Prefer an available Browser, Chrome, or Playwright tool. Otherwise follow the shared browser fallback and use `agent-browser` once it is available.

For each candidate:

1. Open the page and find the closest heading and paragraph that could naturally contain the link.
2. Record the page title and a 2–4 sentence excerpt around that passage.
3. Capture a focused screenshot when the browser supports it, and retain its path or URL.
4. Keep the observed passage separate from the proposed anchor and outreach angle.

If the page cannot be inspected, omit it from the recommended shortlist or label it as unvalidated rather than inventing evidence.
