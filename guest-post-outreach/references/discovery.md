# AI-first prospect discovery

Read this reference only when the user wants the agent to find guest-post prospects.

## Choose the search path

Inspect the runtime in this order:

1. a callable web-search or SERP MCP/API;
2. an interactive Browser, Chrome, Playwright, or computer-use tool that can use the user's current search session;
3. `agent-browser`, when available under the shared tooling contract.

If none is available, explain that live discovery cannot continue. Offer the human-first path with user-provided domains or a local search export. Do not present remembered or guessed sites as live prospects.

Use the result source the tool actually provides. If the user specifically requires Google results, pause rather than silently substituting another engine.

## Search in two passes

For each of the one to three verified focus topics, begin with the user's requested pattern:

```text
"write for us" TOPIC
```

If the first pass is thin, add a small set of distinct variants:

```text
"guest post guidelines" TOPIC
"contributor guidelines" TOPIC
intitle:"write for us" TOPIC
inurl:write-for-us TOPIC
TOPIC ("submit an article" OR "become a contributor")
```

Localize queries only when the target country or language warrants it. Translate the editorial phrase naturally instead of mechanically translating each word.

Run enough queries to produce a useful shortlist, then stop. More results are not progress once new queries mostly return duplicate or low-fit domains.

## Validate and deduplicate

Keep the result page that states the contribution policy, not a generic homepage. Normalize scheme, `www`, fragments, tracking parameters, and trailing slashes before deduplication. Treat different publications under one parent company separately only when they have separate editorial policies.

Open each candidate and verify:

- the guidelines are current enough to act on;
- the publication covers the chosen topic for the intended audience;
- recent articles show real editorial activity;
- the page gives a usable submission route;
- any external-link, payment, or exclusivity terms are visible.

Search snippets are discovery clues, not qualification evidence. A candidate remains `uncertain` until its page is inspected.

## Add optional SEO-provider evidence

Use this section only when a callable Ahrefs, Semrush, DataForSEO, equivalent SEO MCP, or a matching local export is available. Do not block basic discovery when it is missing.

For each serious candidate, collect the provider's named metrics for:

- estimated organic traffic and the measurement date;
- the provider-specific authority metric, such as Domain Rating or Authority Score;
- current ranking keywords and the country, language, device, and database used;
- referring-domain or backlink data when it helps explain the site's organic footprint.

Compare the candidate's ranking keywords and ranking URLs with the user's verified focus topics. Look for meaningful topic and audience overlap, useful non-brand intent, and a publication that appears to attract the intended readers. Treat traffic and authority as directional signals, not proof of editorial quality or acceptance likelihood.

Record spam-risk signals instead of declaring a domain "non-spam." Signals can include a large unrelated keyword mix, irrelevant high-volume clusters, thin or autogenerated-looking pages, or a sharp mismatch between the site's claimed topic and its ranking footprint. Keyword data alone cannot prove a site is spam.

Keep the provider name, collection date, scope, and observed values beside every metric. Do not compare scores from different providers as if they were equivalent. If provider data conflicts with the page evidence, show both and lower confidence rather than resolving the conflict by assumption.

## Prioritize

Use a 1 to 5 score for:

- audience and topic fit;
- editorial quality and recent activity;
- fit between the user's evidence and the site's content;
- clarity and feasibility of the submission process;
- editorial value beyond the backlink.
- optional organic footprint and topic alignment from an SEO provider, as a tiebreaker only.

Average the available dimensions and explain any deliberate override. Use the score to order research, not to predict acceptance. Editorial fit and a usable submission route outrank traffic or authority metrics.

Return the query used and guidelines URL for every shortlisted domain so another run can reproduce the discovery.
