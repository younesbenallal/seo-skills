# Approved backlink outreach and submission

Read this reference only when the user wants the agent to contact a publication or page owner, or submit an application.

## Authorization gate

Show the final recipient or form URL, subject, message, attachments, author identity, proposed links, and any fee. Ask for explicit approval immediately before sending or submitting.

For a batch, obtain approval per prospect or for a clearly enumerated batch whose final messages are all visible. A prior request to research, draft, or "automate the process" is not submission approval.

If the site changes a material term during submission, such as a fee, rights transfer, exclusivity clause, account creation, or link policy, pause and ask again.

## Choose one published route

Follow the route provided by the site or platform. Avoid contacting the same recipient by form and email unless it asks for both.

When email is published for submissions:

- prefer a visible `mailto:` link or address in the rendered guidelines/contact page;
- normalize deliberate text forms such as `name [at] domain [dot] com` and HTML entities;
- use the address only for the stated editorial purpose;
- do not guess private addresses or use unrelated personal-contact enrichment.

When the site requires a form:

1. Open the form with the available browser or computer-use tool.
2. Fill only approved information.
3. Upload only the approved files.
4. Review the complete form and show the user any new material term.
5. Submit after the authorization gate has passed.

The agent may use ordinary interactive controls and the user's existing authenticated session. If a CAPTCHA, one-time code, device confirmation, or other human challenge appears, pause for the user to complete it. Resume after the user confirms. Do not bypass access controls or claim that a challenge was solved.

Do not accept terms, create an account, consent to marketing, or pay a fee unless the user explicitly approved that action.

## Verify and record

After submission, capture one of:

- the email connector's sent-message result;
- the form's confirmation page or confirmation identifier;
- a screenshot showing the successful submission state.

Update the website's section in the campaign Markdown after submission. Add the send date and set the status to `contacted` only when the email connector or form gives a sent/submission result. If the UI gives no confirmation, write `Status: submission uncertain`, describe the observed state in the notes, and stop. Do not retry automatically because a duplicate pitch can harm the relationship. On resume, an uncertain submission requires an explicit user decision before any retry.

Any follow-up message is a new external action. Draft it when requested and obtain approval before sending.
