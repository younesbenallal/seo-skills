# Niche-edit outreach

Read this reference when the user supplies an existing page and wants to ask its publisher to add a link to the user's content.

## Inspect the page

Start with the exact URL the user supplied. Confirm the page is live, identify its audience and main topic, and read the section where a link could add value. Record the page title, URL, relevant passage, and the reason a new source would help the reader.

Check whether the page already links to the user's site, a competitor, or a similar resource. A competitor link is evidence that an editorial link may be plausible, not a reason to demand parity. Do not claim that a competitor link proves the publisher will accept the request.

Find the site's published contact route. Prefer an editorial or site-owner email, a contact form, or an authenticated platform message such as Substack when the user has access. Use the route the site provides and record the destination. If no route is available, return a copy-ready message and the blocker.

## Match the user's content

Read the user's blog index or sitemap and use the source-topic map in the main skill. Open the most relevant candidate pages, not just their slugs. Recommend the best existing URL only when it genuinely supports the passage on the prospect page.

For the recommendation, state:

- the user's URL and what it adds;
- the exact section or claim where the link could fit;
- a truthful, non-forced anchor suggestion, if useful;
- any evidence, process, data, or example that makes the page a better source;
- why the link improves the reader's next step.

If no existing page is a good fit, say so. Offer a different URL or a short content gap to fill. Do not invent statistics, imply an unpublished page exists, or recommend a link only because it contains a target keyword.

## Draft the ask

Keep the request short and specific. Identify the page and section, explain the reader benefit, provide the suggested URL, and leave the publisher free to accept, edit, or decline. Mention a correction or useful update when one exists. Avoid promises about rankings, traffic, or reciprocal links.

If the publisher asks for payment, sponsored placement, login access, or a change to link attributes, show the term to the user and wait for approval. A niche edit is an editorial request, not permission to alter the page or accept a commercial arrangement.

## Completion criterion

The niche-edit package is complete when it contains the inspected prospect URL, contact route or blocker, one evidence-backed target URL, the proposed placement and reader value, and an approval-ready message. Use [submission.md](submission.md) for the final authorization and submission steps.
