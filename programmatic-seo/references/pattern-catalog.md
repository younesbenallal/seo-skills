# pSEO pattern catalog

Use this catalog as reference when choosing a scalable page family. Each pattern needs page-specific data and a real intent match; the examples are illustrative, not demand validation.

1. **Templates** — `[type] template`; `/templates/[type]/`; usable templates and meaningful variations.
2. **Curation** — `best [category]`; `/best/[category]/`; genuine evaluation, testing, and updates.
3. **Conversions** — `[X] to [Y]`; `/convert/[from]-to-[to]/`; accurate data and a functional tool.
4. **Comparisons** — `[X] vs [Y]` or `[X] alternative`; `/compare/[x]-vs-[y]/`; honest feature data and recommendations.
5. **Examples** — `[type] examples`; `/examples/[type]/`; high-quality examples with analysis.
6. **Locations** — `[service] in [location]`; `/[service]/[city]/`; local data and location-specific insights.
7. **Personas** — `[product] for [audience]`; `/for/[persona]/`; persona-specific needs, features, and proof.
8. **Integrations** — `[product] [other product] integration`; `/integrations/[product]/`; real setup details and use cases.
9. **Glossary** — `what is [term]`; `/glossary/[term]/`; clear definitions, examples, and related terms.
10. **Translations** — localized versions of a page; `/[lang]/[page]/`; quality translation and cultural localization.
11. **Directory** — `[category] tools`; `/directory/[category]/`; comprehensive listings with useful filtering.
12. **Profiles** — `[person/company]`; `/people/[name]/`; accurate, sourced information and unique insight.

Patterns may be combined only as a primary pattern plus a meaningful modifier, such as Locations + Personas. Treat that as one page family with explicit combined data and intent—not as permission to multiply pages without additional value.
