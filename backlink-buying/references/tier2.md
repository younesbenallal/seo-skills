# Tier 2 and relinking

A Tier 2 link points at a page that already links to the user's site (a Tier 1 source), to make that page stronger and get it crawled. Marketplaces usually accept any target URL, so a Tier 2 order is a normal order with a third-party target.

## Choose the Tier 1 sources to push

List the existing backlinks to the target pages from the purchase log and the SEO data provider. Keep only sources that are:

- live, dofollow, and pointing at the right page with a sensible anchor;
- indexed. A recently bought link that is not indexed yet is not a candidate; wait for indexation and come back;
- on a domain with real traffic, or a page with its own backlinks. Pushing a page on a dead domain wastes the budget.

Check first that the user's target page receives the value: if the Tier 1 links point at a landing page that never links to the page that ranks, fix that internal link before paying for Tier 2.

## Build the basket

- Use the relaxed vetting profile from [vetting.md](vetting.md). Cheap, clean, on-topic sites are fine.
- Group several Tier 1 sources in one article when the site allows several links, each link in its own paragraph.
- Exact-match or keyword-rich anchors are acceptable here, unlike on Tier 1 links.
- When a Tier 1 article allows more than one link, its extra links can point at existing Tier 1 sources: it is a free Tier 2.
- Linking Tier 2 articles to each other, or to parasite pages, is possible when the user asks for it.

## Relinking with Linkuma

Linkuma sells relinking packs: 3, 5, or 10 Tier 2 articles on a post it already published, written and published by Linkuma one per day. It is the shortest path for Tier 1 links bought on Linkuma: list the published posts from the project, apply the checks above, then buy a pack per post. For a Tier 1 source bought elsewhere, order a Linkuma `basic` or `standard` article with that source as the target URL. See [linkuma.md](linkuma.md).

Present and approve the basket like any other (SKILL.md, step 6). Record each Tier 2 order in the purchase log with the Tier 1 source as its target and tier `2`.
